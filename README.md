Second Chance Paw & Hope Animal Rescue

Tagline: Rescuing pets. Restoring hope. Reuniting hearts.
1. Project Overview

Second Chance Paw & Hope Animal Rescue is an animal rescue website designed to provide information about rescued animals and encourage people to adopt, volunteer and donate.

I created this website as it aims to help rescued animals find loving homes while making it easier for visitors to learn about the organisation and get involved.

2. Website Pages

The website contains the following pages:

Home: Introduces the animal rescue organisation.
About Us: Provides information about the organisation and its purpose.
Adoption: Displays animals available for adoption and includes a pet search feature.
Pet Profiles: Provides information about individual rescued animals.
Volunteer: Allows visitors to complete a volunteer form.
Donate: Provides a donation form for visitors who want to support the organisation.
Contact Us: Allows visitors to submit enquiries through a contact form.

3. Technologies Used
HTML5: Used to structure the website.
CSS3: Used to style the website and create a responsive layout.
JavaScript: Used to add interactive features and form validation.

4. Website Features

The website includes:

Interactive buttons on the Home and About Us pages.
A pet search feature on the Adoption page.
Volunteer, donation and contact forms.
JavaScript form validation and feedback messages.
Clickable pet profile images that open in a larger view.
Responsive styling for different screen sizes.
SEO files, including `robots.txt` and `sitemap.xml`.

5. Website Design
The website uses a colour scheme consisting of gentle teal, sky blue, sunny yellow, white and navy blue. These colours create a friendly and welcoming appearance suitable for an animal rescue organisation.

6. Folder Structure

Css:  Contains the external stylesheet (`style.css`).
js: Contains the JavaScript file (`script.js`).
Images: Contains website images and the organisation logo.
HTML files: Contain the different website pages.
robots.txt: Provides instructions for search engine crawlers.
sitemap.xml: Lists the website pages for search engines.

8. Conclusion

Second Chance Paw & Hope Animal Rescue combines HTML, CSS and JavaScript to create an informative and interactive animal rescue website. The website encourages visitors to support animal rescue through adoption, volunteering and donations.
